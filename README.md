# salon-plus

Сайт парикмахерской «Салон-Плюс» в Калининграде.

**Сайт:** https://suredkek-spec.github.io/salon-plus/

## Запуск и сборка

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Локальный сайт: http://127.0.0.1:3000/salon-plus/

```sh
npm run build
```

Сборка создаёт готовый статический сайт в `docs/` из React-компонентов, стилей и фотографий. Сервер и база данных не нужны.

GitHub Pages публикует папку `docs/` из ветки `main`. После изменений выполните сборку и сохраните обновлённые файлы `docs/` в репозитории.

Услуги и телефон: `app/data.ts`. Разметка: `app/page.tsx`. Стили: `app/globals.css`.

Запись по телефону. Подтверждённую ссылку YCLIENTS можно указать в `YCLIENTS_BOOKING_URL`.
